给 Hexo 博客接入 Twikoo 评论系统：从 MongoDB 到 Vercel 的完整踩坑记录

YuAn2026-11-042026-11-04

静态博客（Hexo、Hugo 这类）本质就是一堆提前生成好的 HTML，没有数据库、没有后端接口，所以「评论」这件小事反而成了最麻烦的一步。

本文记录我给这个博客接入 Twikoo 评论系统的完整过程：从 MongoDB 建库、Vercel 部署云函数，到前端配置和踩坑排查。整套方案全程免费，不需要服务器，也不需要备案。

一、为什么选 Twikoo

常见的静态博客评论方案大致这几家：

方案 后端 免费额度 特点
Valine LeanCloud 有 老牌，维护节奏慢
Waline Vercel / 自建 + 数据库 有 功能全，配置项多
Artalk 需要自己部署服务端 无 功能强，但要服务器
Twikoo 一个 Serverless 云函数 + MongoDB 有 部署最简单，前端只挂一个 js

选 Twikoo 的理由很实际：

  • 后端就是一个云函数，Vercel 点几下就部署完，不用买服务器；
  • 数据库用 MongoDB Atlas 的免费集群，512MB 对个人博客绰绰有余；
  • 前端只引一个 twikoo.all.min.js，主题基本都有现成支持（我用的 anzhiyu 主题内置）；
  • 支持邮件通知、微信提醒、反垃圾、Markdown、表情、头像墙，该有的都有。

三、第一步：MongoDB Atlas 建免费库

  1. 打开 https://www.mongodb.com/cloud/atlas/register 注册账号（用邮箱即可，不用信用卡）。
  2. 创建集群时选 M0 Free，区域挑离你近的（比如 Singapore / Hong Kong），免费额度 512MB。
  3. 左侧 Database Access → Add New Database User：
    • 认证方式选 Password；
    • 用户名例如 blog_user，密码自己生成一个纯字母数字的（别用特殊符号，后面拼连接串容易出事）；
    • 权限保持默认 Read and write to any database。
  4. 左侧 Network Access → Add IP Address → 选 Allow Access from Anywhere（0.0.0.0/0）。

    Vercel 的出口 IP 是动态的，不放开这个，云函数连不上库。

七、我实际踩的六个坑

这部分是本文的重点，基本都是「照着教程做，但就是不行」的场景。

坑 1：Vercel 的 Create 按钮是灰的，点不动

导入模板后，项目名那一栏我填了中文「我的仓库」，Create 按钮一直灰着。

原因：Vercel 的项目名 / 仓库名只允许小写字母、数字和连字符。
解决：改成 twikoo 就好了。

坑 3：接口报「未设置环境变量 MONGODB_URI」

云函数跑起来了，但读不到环境变量。两个常见原因：

  1. 变量只加到了 Preview / Development，没加到 Production；
  2. 加完变量没有 Redeploy。

解决：确认 Environments 勾了 Production，然后重新部署一次。

坑 4：querySrv ENOTFOUND _mongodb._tcp.cluster0.el1czh0.mongodb.net

这个报错最有迷惑性——连接串看起来完全正常，但 DNS 就是解析不到。

原因：集群主机名里有个字母 l（小写 L），被我看成了数字 1。eliczh0 抄成了 el1czh0，域名自然不存在。

排查方法：把连接串里的主机名抠出来，直接查 SRV 记录：

  • 返回 "Status": 0 且带 Answer → 域名正确，问题在别处；
  • 返回 "Status": 3（NXDOMAIN）→ 域名就是错的，回去逐字符核对主机名。

教训：主机名、密码这种要手抄或从截图里认的字符串，别信眼睛，用 DNS 查一遍。

坑 6：评论区顶上一直挂一条黄色警告

部署完能评论，但评论区顶部有条提示，大意是「前端版本 1.6.44，后端版本 2.0.17」。

原因：主题自带的 Twikoo 前端 js 版本太老，和后端不匹配。Twikoo 的前后端版本不一致时会主动提示。
解决：把 themes/anzhiyu/plugins.yml 里的 version 改成和后端返回的 version 一致（我这里是 2.0.17），然后 hexo clean 重新构建。

八、收尾：让部分页面不显示评论

接完评论后我发现，相册页、说说页这类纯展示页面底部也长出了评论区，很怪。

anzhiyu 的判断逻辑是 if page.comments !== false，只要 front-matter 里没写 comments，就默认渲染。

九、成本说明

项目 免费额度 够不够用
Vercel Hobby 云函数 100GB-hours/月 个人博客远远用不完
MongoDB Atlas M0 512MB 存储 评论数据纯文本，能用很多年
Twikoo 开源免费 —

唯一要注意的是：MongoDB 免费集群长期无访问可能会被暂停，登录 Atlas 控制台点一下恢复即可；Vercel 的免费项目长期无访问也会休眠，第一次访问慢几秒，之后正常。

结语

整套流程真正花时间的不是「部署」，而是那几个报错——尤其是 querySrv ENOTFOUND，一个字母看错能耗掉半小时。

如果你也在搭，建议按这个顺序验证，出问题能立刻定位在哪一层：

  1. 浏览器直接访问云函数域名 → 有没有返回 code: 100；
  2. 有返回但报 1000 → 环境变量 / 重新部署的问题；
  3. 返回了别的错、带 querySrv / MongoServerError → 连接串的问题，先查 DNS；
  4. 云函数完全正常但页面不显示 → 前端 envId 或版本不一致。

按这四层排查，基本不会卡住。
