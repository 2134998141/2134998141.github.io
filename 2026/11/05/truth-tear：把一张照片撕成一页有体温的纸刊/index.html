truth-tear：把一张照片撕成一页有体温的纸刊

YuAn2026-11-052026-11-05

旅行拍了一张很喜欢的照片，想做成海报发朋友圈。直接发原图太素，加滤镜又像旅游打卡照。想做成那种独立杂志的拼贴感——撕纸边缘、手写字体、旧纸底——但每次跟 AI 说「做成 zine 风格」，出来的要么是干净的数字蒙版，要么是一堆贴纸胶带和乱码英文。

问题不在于模型画得不好，而在于「一页好看的撕纸纸刊」是一堆模糊的审美要求，模型每次只能猜中其中几条。

我把这件事写成了一个 Skill：truth-tear。它不追求「画得惊艳」，而是把「什么样才算合格的撕纸纸刊」拆成可以逐条打勾的硬约束——真景为锚、撕纸成窗、插画成场、色彩成结构、文案成魂、纸面会呼吸。

这篇记录它的审美判断、六条美学支柱、那些必须写成数字的几何门禁，以及我用南京梧桐照片跑出来的四张成品。

一、先看结果

这是用一张南京中山陵梧桐大道的真实照片做的。金色梧桐隧道、穿黄裙走过斑马线的女孩、红色路牌全部保留为摄影真景，四周是暖米白做旧纸底，撕口边缘长出水墨梧桐枝，金色笔刷从实景秋叶跨界连到手绘墨枝上。

换一张照片（梧桐林下穿白裙奔跑的女孩）、换三种裂口，气质立刻不一样。把四张成品并排看最清楚：

中央开窗最像「从纸里窥见秋天」，轮廓顺应让主体从纸面生长出来，边缘环窗最克制——只在一侧露出纸的手作感。裂口决定了情绪方向，而裂口不是随机选的，下面讲为什么。

二、审美核心：克制比丰富更难

一句话审美：把一张真实的照片，做成一张有体温的旧纸刊。

美在克制与手作，不在丰富与精致。这一页要让人停一下，不是让人看一遍。拿到照片后先「品」五件事再动手：

  1. 品气质——第一感觉是静谧、温润、苍茫，还是日常温暖？它决定情绪与整体基调。
  2. 品焦点——最值得留下的瞬间是什么？一盏灯、一条河、一个背影、一道光？它就是撕纸开窗要护住的锚。
  3. 品留白——哪里可以空出来？空处放插画场、放文字，还是纯纸呼吸，才能加分而不是填满。
  4. 品颜色——原图里最动人的一种颜色是什么？提炼为唯一高饱和结构色。
  5. 品对话——真实与手作在哪一点相遇？真实灯笼→手绘红线，真实水波→墨色纹理，真实山脊→金色勾勒。

每个创作决定都要过一道「审美天平」：

往这边压（加分） 往这边收（减分）
克制——少即是多，一处色、几处母题、几句文字 堆砌——什么都要，元素塞满
留白——纸在呼吸，空是主动设计 填满——处处都有东西，窒息
手作痕迹——纸纤维、墨迹、磨损、印刷瑕疵 光滑精致——塑料感、AI 平滑、数码完美
含蓄——用意象说话，情绪浮现而非喊出 直白——口号、广告腔、大字头条
单一笃定色——一种色定全页 花哨——多色杂陈，视觉打架
文字如版画——字形融入纸纹，是构图一部分 文字如海报——大字号排版压过画面
纯二维诚实——物性是直的 3D／投影炫技——把纸当屏幕

一眼就不美的反例也写死在技能里：商业广告感、元素堆满、光滑塑料、直白大字、照片嵌框、无留白、多色杂陈、无手作温度。

三、六大美学支柱

1. 撕纸成窗——核心结构

摄影与纸面的交接处必须是手工撕纸的纤维边缘，不是干净的数字蒙版。裂口位置和形态由原图决定，四选一，不混用：

逻辑 什么时候用 怎么撕
轮廓顺应 主体轮廓清晰（树、山脊、建筑、桥沿） 沿轮廓撕开，主体似从纸面生长
空间分割 有透视线（河流、街道、海岸、铁路） 沿透视做对角／侧边撕裂，形成空间对峙
焦点开窗 单一核心焦点（灯笼、门洞、船、亭、窗） 纸面中央撕不规则孔洞露出局部
边缘环窗 大部分要保留实景 仅一侧／一角撕纸收口

关键是平面拼贴咬合，不是照片嵌框：插画元素必须从撕口边缘生长出来并压叠照片边缘，实景居一侧约 40–60%；严禁照片被纸面四周均匀包围——那像相片框，不像纸刊。

更硬的是「撕口几何四条」，每条都要换算成数值写进提示词：

# 参数 硬指标
1 振幅节奏 至少 3 段不同振幅：细密段（短边 0.3–0.5%）、中等段（1–2%）、一段近乎平直（占撕口 20–30%）。全程等幅扇贝边＝不合格
2 须边宽度 裸露纤维 ≤ 短边 1%，只在照片一侧可见，不可两侧对称
3 咬合断口 撕口上先定 2 个真实结构断口（枝／屋檐／岸线／路沿），插画笔触从这 2 点起步并压过照片 4–8% 宽度，中间不留缝
4 撕裂范围 覆盖照片可见周边 35–70%，至少一条边保持硬切出血

2. 真景为锚

撕口内保留真实摄影质感与关键空间关系（朝向、地平线、透视、动线）。照片提供事实，创作决定如何留下它。实景区域内不得混入任何手绘元素——插画就是插画，照片就是照片，两者只通过撕口边缘相遇。

还有一条容易忽略的「同纸感」：照片整体要向纸底暖米色偏一档，交界处留 1–2% 宽的极轻油墨网点／褪色过渡，让两者读作同一张纸；禁止滤镜化、磨皮、HDR 增强、暗角。否则再好的撕口也会显得像「数码相片贴上去」。

3. 插画成场

撕口外的纸面以手作媒介延展，但图形稀疏、留白为大头。插画不是装饰墙，而是原照片的低细节视觉回声——删掉 60–80% 的琐碎细节，合并为大面积剪影、断续线稿或墨块；一个主媒介 + 至多一个同源辅助：

媒介 适合题材
水墨国风 山水、水乡、山居、梅枝、村落、飞鸟
版画／木刻剪影 城市、海港、公路、建筑、行人
印刷纹理（网点／波浪） 海、水、天空
墨晕＋金笔 江河、路线类轨迹

配重也有数值：主插画母题必须跨越画面高度的 2 个三分带，九宫格里至少 3 格完全空白，任一格内不同时出现 3 个以上视觉元素。严禁水墨枝、结构色、文案三样全挤在同一条水平带——那会把上方留白变成死白。

4. 色彩成结构

除了中性墨色，只用一种高饱和印刷色做构图骨架——朱红／橙、群青／钴蓝、绿、或金，取自原图色彩或题材气质。它以圆块、波浪、笔刷、印章承载，并且跨界连接真实与插画：真实秋叶是金的，手绘墨枝上就有金色叶点；真实灯笼是红的，手画线就用朱红。

结构色同样有六条硬指标，挑四条最关键的：面积 3–8%（原图已高饱和时 3–5%）、必须渐隐或网点化进入照片（不透明度从 0 递增，过渡跨度 ≥ 画面高度 6%，严禁硬边横切主体）、上边缘顺一条真实轮廓走（偏差 ≤ 画面高度 2%，严禁水平直边）、以及移除测试——删掉色块后画面必须失去配重或失去真实↔纸的桥，如果只是「少了点颜色」，说明这个色块没承担结构职责，重设。

顺带一条选色经验：原图已高饱和（秋叶／夕阳／霓虹）时，结构色要对比补位（暖底上群青，冷底上朱红），同色系会直接消失；原图低饱和（雾／灰城／雪）才用同色系强化。

画面出现水面时另有一套水域铁律：水线不画、倒影不重画、色不与另一条轴交叉、量感要够（溶解区≥15% 面积）。水从来不是「画」出来的，而是照片里的水面用网点溶进纸里。

5. 文案系统

文字是这个风格的灵魂，按画面需要三选一：

  • 完整双语（水墨／传统题材）：中文书法标题 + 繁体题诗 + 英文诗意短句 + 红色印章 + 微缩编辑标记
  • 英文诗意层叠（城市／街头／公路）：纯英文 2–4 句递进，无中文标题、无印章
  • 轻文案（纯净水域／山谷）：仅一行英文诗意短句，留白最大化

文本清单硬约束：所有可见文字逐字列成清单写进 prompt，写明位置、层级、字数上限，并显式声明「除清单外不得出现任何其他文字」。中文必须繁体正体（霧／鄉／裏，禁简体），微缩标记逐字符固定为 Zine v1.3（禁写成 Ver／Version），英文大小写与分行按清单原样。这是硬约束，因为模型最爱在角落自创英文、把繁体写成简体、把标记悄悄改掉；生成后还得下载原图逐字核验，缩略图 OCR 不可信。

6. 纸面会呼吸

暖米白做旧艺术纸底，细腻纤维、克制斑点、轻微扫描噪点、平面油墨吸附感，可带局部水渍／折痕。纯二维，无 3D、无投影、无卷曲纸角。大留白不是没填满，是主动设计。

把这些规则收拢成一张速查图，生成前逐条过一遍：

任何一条给不出具体数值或可观察判断标准，说明构图还没定完——回上一步重定，不许用「自然一些／克制一些」搪塞过去。

四、从照片到成品：决策流程

给一张照片 + 一句想要的情绪，技能内部是这样走的：

  1. 读图建卡：识别核心主体、空间关系、方向、色彩氛围、安静区域、语义最小集，判定题材类型。
  2. 定情绪：静谧、慢下来、归处、日常温暖（用户指定则优先），把情绪转成构图／色彩／撕裂／文案的表达方向，而不是贴一个笼统标签。
  3. 决策速查：题材 → 撕纸逻辑 / 主媒介 / 结构色，原图元素冲突时以原图为准（速查表见本节末尾）。
  4. 编文案：按画面需要三选一，逐字写出文字清单。
  5. 编译提示词：把清单文字原样框定，声明除此之外不得有任何文字；只保留能成为可见像素的指令。
  6. 几何清单门禁：把撕口四条、结构色六条、配重与同纸感逐条抄成带数值的清单，缺一条不许开始生成。
  7. 生成 + 质量门：逐项自查撕口、咬合、同纸感、插画配重、结构色、文案、纸张；命中失败只修一个失败项、最多重生成一次，命中兜底即 STOP 交付并记录，不循环。

题材速查表：

题材 撕纸逻辑 主媒介 结构色
山水／山居／村落 轮廓顺应 水墨国风 朱红或金
水乡／河道／街巷 空间分割 水墨国风 朱红
城市／海港／公路 边缘环窗 版画木刻 朱红或群青
单一焦点（灯笼／门洞／船／亭） 焦点开窗 水墨国风 朱红或金

五、实测：南京梧桐的七次生成

用两张南京秋天的照片跑了完整流程，共七次生成：

第一张是中山陵的梧桐大道（金色隧道、斑马线前穿黄裙的女孩、红色派出所路牌），试了三种裂口：横向波浪撕口、不规则开窗、斜向对角线。

第二张是梧桐林里穿白裙奔跑的女孩，又试了四种：轮廓顺应、斜向裂口、焦点开窗、边缘环窗。

上面第一章的四张是从这七次里挑出来最有代表性的。逐张看细节：

轮廓顺应沿树枝下边缘撕开，实景在下、纸面在上，墨枝从撕口长出来压住照片边缘——主体像是从纸里长出来的，最稳，也最有「生长感」。

焦点开窗在纸面中央撕一个有机孔洞，四周大留白，只露出奔跑的女孩和那片最金的树冠。情绪最内敛，像从纸里窥见秋天。

边缘环窗只在右侧留一条窄纸边，左侧大部分实景完整保留，中文标题与英文短句都挤在这条纸边上。最克制的一版，也最像一页真的旧杂志内页。

七张放一起对比，最明显的感受还是那句：裂口决定了情绪方向。横向波浪最稳，斜向最有动感，焦点开窗最像窥见，边缘环窗最克制。

六、踩过的坑

技能经过多轮迭代，下面是实测高发问题与对应补救，都是「症状 → 一线修复 → 兜底」：

症状 一线修复 仍失败兜底
撕纸边宽厚发白像贴纸 强调纸芯暖米白与纸面同色、细而不规则、严禁宽厚白边 减小撕裂面积重生成，仍败交付记录
插画越界压到实景上 重申实景区域内只有真实摄影，插画严格留在纸面侧 强调咬合＋母题压边重生成
照片嵌框构图 改平面拼贴咬合：实景居一侧 40–60%，插画从撕口生长并压叠照片边缘 只修这一项，重生成一次
插画与撕口之间留缝、笔触悬空 指定 2 个真实断口，笔触起点画进照片内侧并压边 4–8% 把主笔触改为横跨撕口的一条长笔
结构色成硬边色带／横切主体 改为不透明度 0 递增渐隐进入（跨度 ≥6%），上边缘顺真实轮廓走 面积压到 3%，改成笔刷触点或波浪
文字自创、错字、标记改写 按文本清单逐字修正文字区，显式禁长段落与自创句 delivered_with_text_issue 交付记录，不循环
插画／色带／文案全挤在一条水平带 主母题上移或拉长，使其跨越 2 个三分带 删掉该带最下方一个元素再重生成
照片数码感与旧纸打架（HDR 贴上纸） 照片向纸底暖米色偏一档，交界加 1–2% 油墨网点过渡 全照片叠 3% 极轻网点统一材质

STOP 规则是这里最值钱的一条：命中任一兜底就立即停止重试、直接交付并记录，禁止无限循环重生成。一次只改一处，才能知道是哪句提示词真的起了作用。

七、用法与交付

丢一张照片，说「做成撕纸纸刊 / 实景拼贴海报 / 加撕纸开窗，想要安静一点的情绪」就会触发。它会读图、定情绪、选裂口与媒介、编逐字文案、过几何门禁，最后返回成品图 + 一到三句创作思路（不主动展示完整提示词）。

技能里除了 SKILL.md，还带决策速查、失败处理表、交付前质量门清单，以及三条可复用的回归测试 prompt。它不追求每次都惊艳，但追求每次都像一页有体温的纸刊——克制、扁平、手作，不像广告，不像数码海报，不像 AI 生成的。

写这个 Skill 最大的收获不是那几张成品图，而是把「我觉得差不多」变成「逐条能打勾」：审美判断仍然要「品」，但品完之后，撕口多宽、色块多大、留白多少、哪几个字能出现，全都有据可查。下次再看到一张「差点意思」的图，我知道该去改哪一个数值了。
